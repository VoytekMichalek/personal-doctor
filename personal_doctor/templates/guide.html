A GUIDE TO YOUR WORKSPACE

Make yourself at home.

A private record of what your Garmin has captured.

Start with Overview

The overview shows the latest imported completed day. Change the chart period to explore your movement. A dash means a reading isn’t available; it never means zero.

Build your history

Open Garmin sync, choose a start and end date, and start the historical import. Summaries arrive first, followed by daily details and activities with original files. A long history can take hours. Closing the page is safe. Pause stops after the current request; Resume continues from the checkpoint. Cancel retains everything already imported.

Automatic updates

While the server is running, recent data refreshes hourly with a seven-day overlap. Older corrections can be retrieved by importing the affected dates again. A local computer must stay on for its worker to run. The deployed server runs its own worker and connects directly to Garmin; it doesn’t depend on your computer.

Check what’s available

Data library lists stored records and date coverage. Some endpoints return empty or partially populated data depending on your device and what you log. A stored response does not guarantee every measurement. Original JSON downloads preserve fields that aren’t shown on the dashboard.

Activity files

Open an activity to download the original ZIP supplied by Garmin, normally containing a FIT file. Manually entered activities may not have an original file. Files are stored with the database, so database backups include the complete archive.

If an import needs attention

Temporary network errors and rate limits retry automatically. For an expired or revoked key, replace GARMIN_PERSONAL_API_KEY in the server’s environment, restart the service, and select Resume. For an unavailable dataset, check the message in Data library. The import continues with other datasets.

Your privacy

The Garmin key stays on the server. This app does not send your data to an AI provider or analytics service. Production access requires the owner password. To change it, generate a new password hash using the project’s password command, update the server environment, and revoke existing sessions with the sessions command. This is a personal archive, not a medical assessment.
